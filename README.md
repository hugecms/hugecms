# ECBoot 电商系统

> 基于 Laravel 的 B2C 自营电商系统，深度融合微信私域运营，一套后台驱动 Web / H5 / 微信公众号 / 微信小程序 / APP 五端卖货。

## 产品定位

**B2C 自营电商 + 微信私域复购增长，双轮驱动。**

- 前台卖货：完整的商品、交易、履约、售后链路，做到"下单到退款"全流程可解释；
- 私域沉淀：微信粉丝、会员、分销资产归一到一个账号体系，触达可分级、召回可降级；
- 营销复购：券、积分、秒杀、分销、专题、种草内容六件套，让每一场活动的让利可核算、归因可追溯。

**适合谁**：需要自营线上商城、同时把微信生态当作用户资产池的品牌商家与中小零售企业。

**与经典开源电商（如 ECShop）的关系**：以 ECShop 2.7.3 数据模型为蓝本逐表重构映射（88 表全闭环），去掉拍卖/夺宝等过时玩法，补齐微信私域、IM 客服、多端支付、分销裂变等现代电商标配。蓝本映射详见 [ECShop 表映射文档](docs/ecshop-2.7.3-tables-domain-mapping.md)。

## 核心能力全景

### 商品

- 多规格 SKU、商品属性体系（类型/属性/属性值三级）
- **五级价格优先级**：秒杀价 > 阶梯价（批量）> 会员价 > 等级折扣 > 原价
- 并发安全库存：`可售 = 库存 - 锁定`，条件更新防超卖，全量库存流水可追溯
- 商品评价：已购验证、晒图、追评，杜绝刷评
- 用户体验层：浏览足迹、收藏、缺货到货提醒（微信订阅消息触达）

### 交易

- 购物车合单、订单全链路快照（收货人/价格/商品名不随主表变化）
- **优惠三源拆分**：券 / 积分 / 促销逐笔记账，每场活动真实让利可聚合核算
- 一单多裹发货、物流轨迹实时缓存
- 售后全流程：仅退款 / 退货退款 / 部分退款按明细摊销，券与积分自动返还，协商全程留痕
- 电子/纸质发票申请与开具

### 支付

- 渠道可扩展（微信支付等），**同一渠道按应用配置不同商户号**——公众号、小程序、APP 各用各的
- 回调幂等三层防护（渠道通知去重 → 支付单状态机 → 业务入账条件更新），对账可重放
- 充值 / 提现申请审核制，资金单据不可物理删除

### 会员与账户

- 手机号 + 微信三端授权（公众号网页 / 小程序 / 开放平台扫码）统一账号，UnionID 跨端归一
- 会员等级按积分自动升级，等级享折扣与专属价
- 钱包：余额与积分双资产，每笔变动必有流水（含 from/to 快照）
- 每日签到赚积分，持续活跃抓手

### 营销增长

- 优惠券：满减/折扣/免邮三类，手动发放、下单赠、注册赠，全生命周期状态管理
- 促销活动：满减 / 折扣，按全场、分类、品牌、商品圈定范围
- 秒杀：独立活动库存原子扣减 + 审计流水 + 超时回补，防超卖可对账
- **两级分销**：用户申请成为分销员，专属带参二维码扫码即绑定，订单完成自动计佣、退款自动失效，提现走申请审核
- 专题页：运营自定义商品聚合落地页，定时上下线
- 内容种草：图文文章挂商品购买入口，评论、点赞、标签、关注社区化互动

### 微信私域

- 公众号粉丝资产独立管理（标签、关注来源、取关留痕），注册后自动关联网站会员
- 触达双通道：公众号模板消息 + 小程序订阅消息（一次性授权次数账本，授权加一、发送减一）
- 带参渠道二维码：分销邀请、商品推广、渠道投放三类，扫码 / 注册转化双计数
- 群发管理：按标签圈人，送达结果回拉
- **三级触达降级**：微信 → 站内信 → 短信，重要消息永不丢；全渠道触达统一视图可查

### 客服

- IM 实时会话（GatewayWorker 承载），会话级已读水位
- 机器人关键词自动应答 + FAQ 自助，转人工兜底
- 智能分配：空闲优先（接待数上限内），忙排队、离线留言站内信提醒
- 话术库快捷回复、满意度评分、咨询带商品 / 订单上下文

### 平台运营

- 广告位定义 + 投放排期、轮播图、导航、友链，全站运营位后台可配
- 搜索热词统计与人工推荐位
- 每日经营统计汇总（订单/交易/会员），明细层与汇总层分离，口径可重算
- 操作日志、登录日志、IP 黑名单、敏感词过滤、短信发送流水——风控与审计完备

## 业务闭环

```
带参二维码/广告位/种草图文
        ↓ 扫码与点击
微信授权 / 手机号注册 → 统一会员（UnionID 归一）
        ↓
浏览·足迹·收藏·搜索热词 ──缺货 → 到货提醒
        ↓
购物车 → 下单（券/积分/促销拆分记账）→ 支付（多端定位，回调幂等）
        ↓
发货（一单多裹·轨迹）→ 确认收货 → 评价（晒图/追评）
        ├─ 售后：退款/退货（按明细摊销返还）→ 客服 IM 全程承接
        ↓
分销计佣 / 等级成长 / 触达召回（微信→站内信→短信）
        ↓
复购 ↺
```

## 多端架构

`system_apps` 应用注册中心统一管理各端身份与密钥（web / h5 / wechat_official / wechat_miniapp / wechat_open / app_ios / app_android）：

- 微信域全表以 appid 隔离——openid、模板、订阅授权、二维码互不串数据，支持多公众号 / 小程序矩阵；
- 换绑微信应用只改配置不动数据；停用应用即一键下线该端；
- 支付渠道按 `(code, appid)` 配置，同渠道不同应用各用各的商户号。

## 技术概览

| 项 | 说明 |
|---|---|
| 框架 | PHP 8.4 + Laravel |
| 数据库 | MySQL，13 业务域 / 91 表 + 1 视图；无外键（应用层状态机条件更新保证一致性）；命名/时间字段/软删全库统一规范 |
| 实时通信 | GatewayWorker（客服 IM） |
| 微信生态 | w7corp/easywechat（公众号 / 小程序 / 开放平台） |
| 任务调度 | Laravel Scheduler + 队列（订单超时关单、秒杀回补、触达降级） |
| 质量工具 | Laravel Pint（风格）、PHPUnit（测试） |

数据表全景、设计规范与核心机制详见 [数据表设计技术文档](docs/database-design.md)。

## 快速开始

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm run build
php artisan serve
```
