## 贯穿性约定（适用于所有任务）

1. **状态流转纪律**：一切状态变更走条件更新（`where status=旧值`），违反项评审一票否决；
2. **资金/积分**：users.balance/points 变动必落 user_account_logs（含 from/to 快照）；
3. **测试**：每任务验收标准中的测试用例为合并前置条件；数据一律走 Factory；
4. **格式**：PHP 改动必须过 `vendor/bin/pint --dirty`；CI 三件套全绿方可合并；
5. **决策依赖**：涉及决策点的任务（2.5.2 / 2.6.4 / 2.7.2 / 3.3 / 4.3 / W2.1）开工前确认已拍板，未拍板即升级 PM。
